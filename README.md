# ROFAMA CAD PRO

Plugin para AutoCAD 2026 voltado a arquitetura, documentação, 3D e expansão para projetos complementares.

## Status
Base em desenvolvimento consolidada a partir da V0.4.

## Compatibilidade alvo
- AutoCAD 2026 Windows 64-bit
- Build .NET 8 para AutoCAD 2026–2026.1.1
- Build .NET 10 planejado para AutoCAD 2026.1.2+

## Recursos atuais
- Paredes paramétricas, padrão 0,15 m
- Portas e janelas com identificação Pxx/Jxx
- Ambientes e cálculo de áreas
- Cotas
- Geração/atualização 3D de paredes
- Recorte experimental de vãos
- Ribbon ROFAMA CAD
- Estrutura para biblioteca DWG

## Roadmap até 1.0
- Esquadrias paramétricas completas
- Quadro gráfico de esquadrias
- Biblioteca DWG real
- Reconhecimento de ambientes
- Cortes, fachadas e cobertura
- Exportação organizada para SketchUp
- Quantitativos
- Elétrica, hidráulica, HVAC e incêndio
- Verificação de projeto e perfis municipais

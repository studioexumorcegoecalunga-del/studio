# Comandos

| Comando | Função |
|---|---|
| RFSOBRE | Ajuda/versão |
| RFPAREDE | Parede paramétrica |
| RFPORTA | Porta |
| RFJANELA | Janela |
| RFAMBIENTE | Rótulo de ambiente |
| RFAREA | Área por polilinha fechada |
| RFCOTAR | Cota alinhada |
| RFESQUADRIAS | Levantamento de esquadrias |
| RFGERAR3D | Gerar paredes 3D |
| RFATUALIZAR3D | Regenerar 3D |

| RFQUADROESQUADRIAS | Gera tabela gráfica de portas e janelas |
| RFPISO | Cria piso a partir de contorno fechado |
| RFLAJE | Cria laje a partir de contorno fechado |
| RFCOBERTURA | Registra cobertura e inclinação |

| RFPORTA2 | Porta arquitetônica com batentes, folha e arco |
| RFJANELA2 | Janela arquitetônica com linhas de caixilho |
| RFGERARLAJES3D | Converte pisos/lajes ROFAMA em sólidos 3D |


## Pavimentos e projeto
| Comando | Função |
|---|---|
| RFCONFIG | Configura parâmetros gerais do projeto |
| RFPAVIMENTO | Cadastra pavimento |
| RFPAVIMENTOATIVO | Define pavimento ativo |
| RFMOSTRARPAVIMENTOATIVO | Exibe pavimento ativo |
| RFLISTARPAVIMENTOS | Lista pavimentos |
| RFVINCULARPAVIMENTO | Vincula objetos existentes ao pavimento ativo |
| RFNIVEL | Insere marcador gráfico de nível |

## Arquitetura adicional
| Comando | Função |
|---|---|
| RFESCADA | Pré-dimensiona/desenha escada reta |
| RFPLATIBANDA | Registra platibanda |
| RFTELHADO2AGUAS | Registra telhado de duas águas |
| RFSIMBOLO | Insere símbolo arquitetônico nativo |
| RFBIBLIOTECA | Abre seleção inicial de categorias |

| RFPLATIBANDA3D | Gera platibanda 3D |
| RFVALIDAR | Faz verificações básicas do desenho |
| RFQUANTITATIVO | Levantamento preliminar |
| RFCORTE | Aciona SECTIONPLANE |
